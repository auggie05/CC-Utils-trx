# CC-utils-trx
trx is a utility to transmit and receive messages in the Minecraft mod CC:Tweaked.

## Current functionality:

Ability to set a computer to receive messages.

Ability to send messages over a modem.

More may be added later.

## Commands:

Use "trx help" to see help.

"trx transmit tx_channel rx_channel message" Transmits message on tx_channel with open reply channel rx_channel. 

"trx receiver rx_channel" Opens rx_channel to replies and prints the replies on screen.

"trx close channel" Closes channel.

"trx closeAll" Closes all open channels.
